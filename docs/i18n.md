# Guía de localización

## Idiomas

| Código | Idioma | Rol |
|---|---|---|
| `es` | Español neutro | Idioma por defecto y de respaldo |
| `en` | Inglés | Segundo idioma |

- En el primer arranque el juego usa `es`, sin importar el idioma del sistema operativo.
- La elección del jugador se guarda en `user://settings.cfg` y se aplica en vivo, sin reiniciar.
- Si falta una clave en el idioma activo, se usa `es`. Si también falta en `es`, se muestra `⟦clave⟧` y se registra. Los tests impiden que eso llegue a una versión, y el smoke test falla si el juego pidió alguna clave inexistente.

## Archivos

Objetos JSON planos de clave a mensaje en `game/content/locales/<idioma>/<dominio>.json`:

| Dominio | Contenido |
|---|---|
| `ui.json` | Menús, HUD, paneles, opciones y calendario |
| `content.json` | Nombre, descripción y género gramatical de cada def |
| `events.json` | Notificaciones y registro de eventos (desde H1.6) |

- Cada idioma tiene los mismos archivos y las mismas claves que el español.
- **JSON estricto:** sin comentarios ni comas finales, porque el editor de Godot también lee los `.json` y no los acepta.

## Convención de claves

| Patrón | Ejemplo |
|---|---|
| `ui.<pantalla>.<elemento>` | `ui.mainmenu.new_game` |
| `def.<categoría>.<id>.name`, `.desc` y `.gender` | `def.plant.oak.name` |
| `job.<id>.report` | `job.chop.report` |
| `event.<dominio>.<evento>` | `event.colonist.starved` |
| `time.*` | `time.season.spring`, `time.date` |

- Minúsculas, palabras unidas con guion bajo y segmentos separados por punto.
- Las claves no se atan a una época: lo que cambia con la época se resuelve con `select` sobre `era`.
- Todo def con textos necesita `name`, `desc` y `gender` en cada idioma. `gender` vale `male`, `female` u `other`; en inglés siempre `other`.

## Formato de los mensajes

`OurLife.Localization` implementa este subconjunto de ICU MessageFormat:

| Sintaxis | Uso |
|---|---|
| `{name}` | Argumento tal cual |
| `{n, number}` | Número con separador de miles del idioma |
| `{n, number, integer}` | Igual, redondeado a entero (mitades al par) |
| `{count, plural, =0 {…} one {…} other {…}}` | Plural; `#` dentro de un caso escribe el número |
| `{gender, select, female {…} other {…}}` | Selección por valor; `other` es obligatorio |
| `''` y `'{'` | Apóstrofe literal y llaves como texto |

Plural:

```json
"ui.items.count": "{count, plural, one {# objeto} other {# objetos}}"
```

Género, a partir de un argumento de entidad:

```json
"event.need.exhausted": "{colonist} está {colonist_gender, select, female {agotada} other {agotado}}."
```

Época:

```json
"ui.settlement.kind": "{era, select, medieval {Aldea} modern {Villa} other {Ciudad}}"
```

- Los enteros se escriben sin separador de miles: un año se lee "1203". Para separadores, `{n, number}`.
- Un argumento que falta se ve como `⟦nombre⟧` en lugar de romper el juego, también el de un `plural` o un `select`.
- En un `select`, un enum elige por su nombre en camelCase, como en los JSON (`Female` elige `female`), y un booleano por `true` o `false`.
- Godot recibe cada mensaje ya formateado sin argumentos. Por eso un control con una clave que necesita argumentos muestra `⟦nombre⟧`: ese texto se formatea con `TextResolver`.

### Argumentos con referencias

La simulación emite `LocalizedText(clave, args)` sin texto final y la presentación expande los argumentos:

| Argumento | Se expande a |
|---|---|
| Otro `LocalizedText` | Su texto ya traducido |
| Colono (un `EntityId`), por ejemplo `{colonist}` | `colonist` con el nombre propio y `colonist_gender` con `female` o `male` (desde H2.6, con las alertas) |
| Def con cantidad, por ejemplo `{item}` (pendiente) | `item` con el nombre en el número correcto e `item_gender` con su género gramatical |
| Época | `era` con `medieval`, `modern` o `contemporary` |

- `ColonyText.Freeze` (Core) reemplaza los colonos por su nombre y su género. Los mensajes del registro salen del Core ya fijados (un colono puede morir antes de que se lean) y el registro los vuelve a fijar al recibirlos; las líneas de alerta del HUD usan colonos vivos.
- La fila de defs llega con el primer texto que la necesite: hasta ahora el inspector arma esos nombres en la presentación.
- Textos que el Core arma en ejecución: `job.<trabajo>.report` para cada trabajo, `event.need.<necesidad>.death` para cada necesidad que mata, y `event.need.<necesidad>.critical` y `alert.need.<necesidad>` para cada necesidad con `alertWhenCritical`. `OurLife.Content.Tests` verifica que existan en cada idioma.

## Proceso para agregar un texto

1. Elegir la clave según la convención.
2. Escribir el texto en `es` y en `en` en el mismo commit, con los mismos argumentos.
3. Usarlo desde la presentación: un control cuyo texto es la clave lo traduce Godot; un texto con argumentos se formatea con `TextResolver`. En Core sólo se emite `LocalizedText`.
4. Correr `dotnet test`.
5. Revisar capturas en ambos idiomas buscando textos cortados.

## Tests

| Test | Proyecto | Qué verifica |
|---|---|---|
| Sintaxis y formato ICU | `OurLife.Localization.Tests` | Plural, select, `#`, comillas, errores claros |
| Paridad | `OurLife.Content.Tests` | Mismos archivos, mismas claves y mismos argumentos que el español |
| Textos de defs | `OurLife.Content.Tests` | `name`, `desc` y `gender` de cada def, sin textos huérfanos |
| Claves usadas | `OurLife.Content.Tests` | Toda clave escrita en el código o en las escenas existe |
| Texto visible | `OurLife.Content.Tests` | Ningún `Text = "…"` ni `text = "…"` que no sea una clave existente y sin argumentos |
| Claves armadas en ejecución | `OurLife.Content.Tests` | `time.season.<id>` y `ui.language.<idioma>` existen en cada idioma |
| Cambio en vivo | Smoke test de Godot | Godot muestra el texto de cada idioma al cambiarlo |

## Estilo

- Español neutro: sin voseo ni regionalismos. Botones y menús en infinitivo o sustantivo ("Nueva partida", "Guardar"); cuando haga falta dirigirse al jugador, de tú.
- Tono sobrio con sabor de época, sin arcaísmos forzados.
- Mayúsculas: en español sólo la primera palabra de un título ("Nueva partida"); en inglés, mayúscula inicial en cada palabra de los menús ("New Game").
- Nombres de objetos y materiales en minúscula; la interfaz decide si van al principio de una frase.
